# EMOSS — ระบบฐานข้อมูลผลลัพธ์การศึกษา

เว็บแอปที่สร้างด้วย **Google Apps Script (HtmlService) + Google Sheets** สำหรับเก็บข้อมูลตัวชี้วัดการศึกษาตามโครงสร้าง **หัวข้อหลัก → หัวข้อย่อย → เอกสาร/ชีตข้อมูล** โดยแต่ละหัวข้อมีหน้าดูเอกสารของตัวเอง พร้อมหน้าตั้งค่า (Config) แยกออกจากหน้าจัดการข้อมูลอย่างชัดเจน

- Frontend: `Index.html` (Bootstrap 5, Bootstrap Icons, SheetJS/XLSX)
- Backend: `รหัส.gs` (Apps Script)
- ที่เก็บข้อมูล: Google Sheets 1 ชีต = 1 เอกสาร/หัวข้อใบ
- โครงสร้างเมนู: ชีตระบบ `_MENU` (ซ่อนอัตโนมัติ)
- Login: Username/Password พร้อม role `admin`, `employee`, `user` — [วิธีสร้าง admin แรกและติดตั้ง](docs/auth-setup.md)

| `รหัส.gs` | ฟังก์ชันฝั่งเซิร์ฟเวอร์: อ่าน/เขียนชีต, นำเข้า Excel, จัดการเมนู |

| `docs/data-model.md` | โครงสร้างชีต `_MENU`, ชีตข้อมูล และแนวทางออกแบบตัวชี้วัด |
| `docs/api-reference.md` | รายละเอียดฟังก์ชัน Apps Script ทั้งหมด |

## เมนูและหน้าในระบบ

| เมนู | หน้า | ใช้ทำอะไร |
|---|---|---|
| ภาพรวมข้อมูล | `dashboardView` | สรุปจำนวนหมวดหมู่/รายการ/คอลัมน์ และความสมบูรณ์ของข้อมูล |
| เพิ่ม / นำเข้าข้อมูล | `entryView` | กรอกข้อมูลรายแถวจากฟอร์มที่สร้างตามหัวข้อคอลัมน์ และนำเข้าไฟล์ Excel |
| จัดการฐานข้อมูล | `dataView` | เลือกชีต, แก้ไขเซลล์ในตารางทันที, ลบแถว, ค้นหา, ดาวน์โหลด Excel |
| เอกสารตามหัวข้อ | `docView` | เปิดทีละหัวข้อ (เฉพาะข้อมูลหัวข้อนั้น) แบบอ่านอย่างเดียว พิมพ์/PDF หรือส่งออก Excel |
| ตั้งค่าเมนู / คอลัมน์ | `configView` | แก้โครงสร้างเมนู, สร้างชีต, ตั้งหัวข้อคอลัมน์ |

หน้า `docView` ไม่มีเมนูตายตัว — สร้างจากโครงสร้างใน `_MENU` (หัวข้อที่มีหัวข้อย่อยจะกดเพื่อย่อ/ขยาย)

## การติดตั้ง

### แบบผูกกับสเปรดชีต (แนะนำ)

1. เปิด Google Sheets ที่ต้องการใช้งาน
2. เมนู **Extensions → Apps Script**
3. วางเนื้อหาไฟล์ `รหัส.gs` ลงใน `Code.gs`
4. สร้างไฟล์ HTML ชื่อ **Index** แล้ววางเนื้อหา `Index.html`
5. ตั้งค่า `SPREADSHEET_ID = ''` (เว้นว่างเพื่อใช้สเปรดชีตที่ผูกอยู่)
6. **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: ตามนโยบายของหน่วยงาน
7. เปิด URL ของ Web app

### แบบสคริปต์แยก (Standalone)

1. สร้างโปรเจกต์ Apps Script ใหม่ วางไฟล์ทั้งสอง
2. ใส่ `SPREADSHEET_ID` ของสเปรดชีตเป้าหมายใน `รหัส.gs`
3. Deploy เป็น Web app เช่นเดียวกัน

> เมื่อแก้โค้ดแล้วต้อง **Deploy → Manage deployments → แก้ไข → New version** ทุกครั้ง ไม่อย่างนั้น URL เดิมจะยังรันโค้ดเก่า (เช่นขึ้น `Script function not found: getMenuConfig`)

## การทำงานครั้งแรก

เมื่อเปิดระบบครั้งแรก `getMenuConfig()` จะ:

1. สร้างชีต `_MENU` (ซ่อน) พร้อมหัวตาราง `id, parent_id, title, sheet_name, icon, sort, note`
2. Seed โครงสร้างตัวอย่าง:
   - `1` การรับเข้าและผลลัพธ์การศึกษา → `1.1` จำนวนลงทะเบียนใหม่ → `1.1.1` ผลการรับเข้าแยกตามรายงาน
   - `2` ผลการเรียนและการคงอยู่ของนิสิต → `2.1` การออกกลางคันชั้นปีที่ 1 จำแนกตามรุ่นเข้า
   - `3` การสำเร็จการศึกษา → `3.1` อัตราสำเร็จตามหลักสูตร (ร้อยละ)
3. สร้างชีตข้อมูลของหัวข้อใบ พร้อมหัวข้อคอลัมน์เริ่มต้น

หลังจากนั้นแก้ไขทั้งหมดได้จากเมนู **ตั้งค่าเมนู / คอลัมน์** โดยไม่ต้องแตะโค้ด

## กฎสำคัญ

- **หัวข้อที่มีหัวข้อย่อยจะผูกชีตข้อมูลไม่ได้** — เก็บข้อมูลที่หัวข้อใบเท่านั้น (ระบบจะไม่ให้บันทึก)
- ชื่อชีตที่ขึ้นต้นด้วย `_` เป็นชีตระบบ จะไม่แสดงในตัวเลือก/สถิติ
- ชื่อชีตห้ามมีอักขระ `[ ] * ? : / \` ตามข้อจำกัดของ Google Sheets
- การแก้เซลล์ในตารางจะบันทึกทันทีเมื่อคลิกออกจากช่อง (หรือกด Enter)

## แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุ/วิธีแก้ |
|---|---|
| sidebar ค้างที่ "กำลังโหลดเมนู..." | `getMenuConfig()` ฝั่งเซิร์ฟเวอร์ล้มเหลว — ตอนนี้จะแสดงข้อความ error และปุ่ม "ลองอีกครั้ง" แล้ว ให้ดูข้อความนั้นหรือ Execution log ใน Apps Script |
| `Script function not found: getMenuConfig` | ยังไม่ Deploy เวอร์ชันใหม่ |
| `ไม่พบไฟล์ Google Sheets` | ไม่ได้เปิดผ่าน Extensions > Apps Script และยังไม่ได้ใส่ `SPREADSHEET_ID` |
| สร้างชีตแล้วไม่ขึ้นในเมนู | ต้องไปผูก `sheet_name` ให้หัวข้อใบในหน้าตั้งค่า แล้วกด "บันทึกโครงสร้าง" |
| ชีตไม่แสดงในตัวเลือก | ชื่อชีตขึ้นต้นด้วย `_` (ชีตระบบ) |
| บันทึกโครงสร้างเมนูไม่ผ่าน | ตรวจรหัสซ้ำ / หัวข้อแม่ไม่มี / วงจร parent / หัวข้อมีลูกแต่ผูกชีต |
| ปุ่มพิมพ์/PDF ไม่ทำงานในบางเบราว์เซอร์ | ใช้ปุ่ม "ดาวน์โหลด Excel" ในหน้าเอกสารแทน |
