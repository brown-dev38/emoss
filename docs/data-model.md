# โครงสร้างข้อมูล (Data Model)

ระบบใช้ Google Sheets เป็นฐานข้อมูล โดยมี **ชีตระบบ** 1 ชีต (`_MENU`) และ **ชีตข้อมูล** หลายชุด (1 ชีต = 1 เอกสาร/หัวข้อใบ)

```
_MENU (ชีตระบบ, ซ่อน)
 └─ เก็บโครงสร้างเมนูแบบ flat table (id / parent_id)

ชีตข้อมูล (1 ชีต = 1 หัวข้อใบ)
 └─ แถวที่ 1 = หัวข้อคอลัมน์
 └─ แถวที่ 2 เป็นต้นไป = ข้อมูล
```

## 1. ชีต `_MENU`

สร้างอัตโนมัติเมื่อเปิดระบบครั้งแรก และถูกซ่อนไว้ (`sheet.hideSheet()`) แก้ไขผ่านหน้า **ตั้งค่าเมนู / คอลัมน์** เท่านั้น

| คอลัมน์ | ชนิด | คำอธิบาย |
|---|---|---|
| `id` | string | รหัสหัวข้อ ไม่ซ้ำ ใช้เป็น key ของ tree |
| `parent_id` | string | รหัสหัวข้อแม่ (`''` = หัวข้อหลัก) |
| `title` | string | ชื่อที่แสดงในเมนู/หัวเอกสาร |
| `sheet_name` | string | ชื่อชีตข้อมูลที่ผูกกับหัวข้อนี้ (`''` = ไม่ผูก) |
| `icon` | string | ชื่อ Bootstrap Icons เช่น `bi-folder2` |
| `sort` | number | ลำดับภายในระดับเดียวกัน (น้อยไปมาก) |
| `note` | string | คำอธิบายใต้ชื่อในหน้าเอกสาร |

### ตัวอย่างข้อมูล Seed

| id | parent_id | title | sheet_name |
|---|---|---|---|
| 1 | | การรับเข้าและผลลัพธ์การศึกษา | |
| 1.1 | 1 | จำนวนลงทะเบียนใหม่ | |
| 1.1.1 | 1.1 | ผลการรับเข้าแยกตามรายงาน | `1.1.1 ผลการรับเข้าแยกตามรายงาน` |
| 2 | | ผลการเรียนและการคงอยู่ของนิสิต | |
| 2.1 | 2 | การออกกลางคันชั้นปีที่ 1 จำแนกตามรุ่นเข้า | `2.1 การออกกลางคันชั้นปีที่ 1` |
| 3 | | การสำเร็จการศึกษา | |
| 3.1 | 3 | อัตราสำเร็จตามหลักสูตร (ร้อยละ) | `3.1 อัตราสำเร็จตามหลักสูตร` |

### กฎของ tree

1. `id` ต้องไม่ว่างและไม่ซ้ำ
2. `parent_id` ต้องอ้างถึง `id` ที่มีอยู่จริง หรือเป็น `''`
3. ต้องไม่มีวงจร (ตรวจด้วยการไล่ parent พร้อม guard 100 ระดับ)
4. **โหนดที่มีลูกต้องมี `sheet_name = ''`** — เก็บข้อมูลที่หัวข้อใบเท่านั้น
5. `sheet_name` ที่ยังไม่มีอยู่จริงจะถูกสร้างให้เมื่อบันทึก

### การเรียงลำดับ

frontend สร้าง tree จาก `rows` ทั้งหมด แล้วเรียงแต่ละระดับด้วย `sort` (ถ้าเท่ากันเรียงตาม `title`)

## 2. ชีตข้อมูล

- แถวที่ 1 คือหัวข้อคอลัมน์ กำหนดได้จากหน้า **ตั้งค่าเมนู / คอลัมน์ → หัวข้อคอลัมน์**
- แถวข้อมูลเริ่มที่แถวที่ 2
- อ่านค่าด้วย `getDisplayValues()` (ได้ข้อความที่แสดงผลจริงตามรูปแบบเซลล์)
- การแก้ไขในหน้าเว็บเขียนทีละเซลล์ผ่าน `updateSingleCell()`
- ไม่กำหนดชนิดข้อมูลในระบบ — ควรตั้งรูปแบบคอลัมน์ใน Google Sheets เอง (เช่น จำนวนเต็ม, ทศนิยม 2 ตำแหน่ง)

### หัวข้อคอลัมน์เริ่มต้นของ Seed

| ชีต | หัวข้อคอลัมน์ |
|---|---|
| `1.1.1 ผลการรับเข้าแยกตามรายงาน` | ปีการศึกษา, ประเภทรายงาน, หลักสูตร, จำนวนรับเข้า (คน), หมายเหตุ |
| `2.1 การออกกลางคันชั้นปีที่ 1` | รุ่นเข้า, หลักสูตร, จำนวนนิสิตในรุ่น (คน), ออกกลางคัน (คน), หมายเหตุ |
| `3.1 อัตราสำเร็จตามหลักสูตร` | รุ่นเข้า, หลักสูตร, จำนวนแรกเข้า (คน), จำนวนผู้สำเร็จ (คน), หมายเหตุ |

## 3. แนวทางออกแบบตัวชี้วัด

### เก็บจำนวนดิบ ไม่เก็บร้อยละ

เก็บตัวตั้ง/ตัวหารไว้ แล้วคำนวณอัตราเมื่อทำรายงาน เพื่อให้ตรวจสอบย้อนกลับได้

ในหน้า **ตั้งค่าเมนู / คอลัมน์** เลือกหัวข้อและชีตข้อมูล เปิด **แสดงบนแดชบอร์ด** แล้วตั้ง **ค่าที่แสดงบนกราฟ → คำนวณร้อยละ (%)** เลือกคอลัมน์ตัวตั้งและตัวหาร จากนั้นกด **บันทึกโครงสร้าง** ระบบคำนวณ `(ตัวตั้ง ÷ ตัวหาร) × 100` แยกแต่ละแถวและไม่แก้ข้อมูลต้นทาง รองรับกราฟแท่งและกราฟเส้น แสดงทศนิยมสูงสุด 2 ตำแหน่ง และข้ามจุดที่ข้อมูลว่าง ไม่ใช่ตัวเลข หรือตัวหารเป็นศูนย์ ค่าที่เกิน 100% ยังแสดงตามจริง

กด **เพิ่มแท่ง / สูตรร้อยละ** เพื่อเพิ่มหลายชุดข้อมูลในกราฟเดียว แต่ละสูตรเลือกชื่อแท่ง ตัวตั้ง ตัวหาร และสีแยกกันได้ เช่น ผู้สำเร็จ ÷ แรกเข้า × 100 และผู้มีงานทำ ÷ ผู้ตอบแบบสอบถาม × 100 รองรับกราฟแท่งแนวตั้ง แท่งแนวนอน และกราฟเส้น

การตั้งค่านี้เก็บในชีต `_MENU` ผ่าน `chart_value_mode` (`number` หรือ `percent`) และ `chart_formulas` (JSON ของรายการ `{ label, numerator, denominator, color }`) ส่วน `chart_numerator` และ `chart_denominator` คงสูตรแรกไว้เพื่อรองรับข้อมูลเดิม ระบบเพิ่มหัวคอลัมน์ใหม่ให้ชีตเมนูเดิมอัตโนมัติ โดยเมนูเดิมยังแสดงตัวเลขตามปกติ และสูตรร้อยละเดิมจะแสดงเป็นสูตรแรกเมื่อแก้ไข

ตั้งชื่อแกนและป้ายรายการได้ในส่วน **ป้ายแกนหมวดหมู่** แกนนี้เป็น Y สำหรับแท่งแนวนอน และ X สำหรับกราฟแนวตั้ง โดยค่าเริ่มต้นใช้คอลัมน์แรก เลือกคอลัมน์แล้วกด **ต่อชื่อคอลัมน์** เพื่อสร้างรูปแบบ เช่น `{ปีการศึกษา} - {หลักสูตร}` หรือพิมพ์ข้อความร่วมกับชื่อคอลัมน์ในวงเล็บปีกกาเองได้ หากต้องการชื่อเฉพาะให้กรอก **กำหนดชื่อรายการเอง** หนึ่งชื่อต่อบรรทัดตามลำดับแถวที่ไม่ใช่ยอดรวม บรรทัดว่างใช้รูปแบบชื่อเดิม การตั้งค่าเก็บใน `chart_axis_title`, `chart_label_template` และ `chart_custom_labels` กราฟที่แสดงสำเร็จจะไม่มีข้อความรายละเอียดแกนและสูตรใต้กราฟ

| ตัวชี้วัด | เก็บอะไร | สูตรคำนวณ |
|---|---|---|
| อัตราสำเร็จตามหลักสูตร | จำนวนแรกเข้า, จำนวนผู้สำเร็จ | ผู้สำเร็จ ÷ แรกเข้า × 100 |
| อัตราออกกลางคันปี 1 | จำนวนนิสิตในรุ่น, จำนวนออกกลางคัน | ออกกลางคัน ÷ ขนาดรุ่น × 100 |

ถ้าจำเป็นต้องกรอกค่าร้อยละเอง ให้เพิ่มคอลัมน์ `... (ร้อยละ)` แยกและระบุในคำอธิบายหัวข้อให้ชัด

### แยกมิติ `รุ่นเข้า` ออกจาก `ปีการศึกษา`

- `ปีการศึกษา` = ปีที่รายงาน/เก็บข้อมูล
- `รุ่นเข้า` (cohort) = ปีที่นิสิตเข้าเรียน

การออกกลางคันชั้นปีที่ 1 และอัตราสำเร็จตามหลักสูตรอ้างอิง **รุ่นเข้า** ไม่ใช่ปีที่รายงาน จึงควรมีคอลัมน์ `รุ่นเข้า` ในชีตเหล่านี้เสมอ

### มิติที่ควรมีร่วมกัน

- ปีการศึกษา / รุ่นเข้า
- หลักสูตร หรือสาขา/คณะ
- ประเภทรายงาน (ถ้ามีการแบ่งรายงาน)
- หมายเหตุ (เก็บคำอธิบายกรณีข้อมูลผิดปกติ)

## 4. ชีตระบบและข้อจำกัดชื่อ

- ชีตที่ชื่อขึ้นต้นด้วย `_` จะถูกกรองออกจาก `getSheetList()` จึงไม่ปรากฏใน dropdown, สถิติ และการนำเข้า
- ชื่อชีตห้ามมีอักขระ `[ ] * ? : / \` (ข้อจำกัดของ Google Sheets) และยาวไม่เกิน 100 ตัวอักษร
- การส่งออก `.xlsx` จะตัดชื่อชีตเหลือ 31 ตัวอักษรและแทนอักขระต้องห้ามอัตโนมัติ
