# คู่มือใช้งาน

เอกสารนี้อธิบายการใช้งานแต่ละหน้าและขั้นตอนทำงานจริง ตั้งแต่สร้างหัวข้อจนถึงการพิมพ์เอกสาร

## 1. ภาพรวมข้อมูล (`ภาพรวมข้อมูล`)

แสดงการ์ดสรุป 4 ตัว:

| การ์ด | ความหมาย |
|---|---|
| หมวดหมู่งาน | จำนวนชีตข้อมูลทั้งหมด (ไม่นับชีตระบบ `_`) |
| รายการข้อมูล | จำนวนแถวของชีตที่เลือกอยู่ในหน้าจัดการฐานข้อมูล |
| จำนวนคอลัมน์ | จำนวนหัวข้อคอลัมน์ของชีตนั้น |
| คอลัมน์ที่ใช้งาน | เปอร์เซ็นต์ของเซลล์ที่มีข้อมูล (สีเขียว ≥ 50%, เหลือง ≥ 25%, แดงต่ำกว่า) |

## 2. เพิ่ม / นำเข้าข้อมูล (`เพิ่ม / นำเข้าข้อมูล`)

หน้านี้ทำงานกับ **ชีตที่เลือกไว้ในหน้าจัดการฐานข้อมูล** (ใช้ `currentSheet` ร่วมกัน)

### 2.1 กรอกข้อมูลรายแถว
- ฟอร์มจะถูกสร้างจากหัวข้อคอลัมน์ของชีตนั้นอัตโนมัติ
- ถ้าชีตยังไม่มีหัวข้อคอลัมน์ ปุ่มบันทึกจะถูกปิดและมีข้อความแนะนำให้ไปตั้งค่าที่เมนู "ตั้งค่าเมนู / คอลัมน์"
- กด "เพิ่มรายการลงตาราง" แล้วแถวใหม่จะถูกเพิ่มลงชีตและไฮไลต์ในตาราง

### 2.2 นำเข้าจากไฟล์ Excel
1. เลือกไฟล์ `.xlsx`, `.xls` หรือ `.csv` (อ่านเฉพาะชีตแรกของไฟล์)
2. เลือกโหมด
   - **นำเข้าต่อท้ายข้อมูลเดิม** — จับคู่คอลัมน์ด้วยชื่อหัวข้ออัตโนมัติ ถ้าไฟล์มีคอลัมน์ใหม่ที่ชีตยังไม่มี ระบบจะเพิ่มคอลัมน์ให้
   - **ล้างตารางเดิม** — ล้างข้อมูลทั้งชีต แล้วเขียนหัวข้อ+ข้อมูลจากไฟล์นี้ทั้งหมด
3. กด "อัปโหลดและนำเข้าข้อมูล"

แถวที่ว่างทั้งแถวจะถูกข้าม

## 3. จัดการฐานข้อมูล (`จัดการฐานข้อมูล`)

- เลือกชีตจาก dropdown (แสดงทุกชีตที่ไม่ขึ้นต้นด้วย `_`)
- **แก้ไขในตาราง**: คลิกที่เซลล์แล้วพิมพ์ได้ทันที, กด Enter หรือคลิกออกเพื่อบันทึก (มี toast แจ้ง)
- **ลบแถว**: ปุ่ม "ลบ" ท้ายแถว จะถามยืนยันด้วย modal ของระบบ
- **ค้นหา**: ช่องค้นหากรองแถวตามข้อความ (ฝั่งเบราว์เซอร์)
- **ดาวน์โหลด Excel**: ปุ่มมุมขวาบน ส่งออกชีตปัจจุบันเป็น `.xlsx`

> การตั้งหัวข้อคอลัมน์และสร้างชีตใหม่ย้ายไปอยู่ที่หน้า **ตั้งค่าเมนู / คอลัมน์** เพื่อแยกงาน config ออกจากงานข้อมูล

## 4. เอกสารตามหัวข้อ (`เอกสารตามหัวข้อ`)

เมนูชุดนี้สร้างจากชีต `_MENU` โดยตรง

- **หัวข้อที่มีหัวข้อย่อย** (เช่น 1, 1.1) — คลิกเพื่อย่อ/ขยาย
- **หัวข้อใบที่มีชีตข้อมูล** — คลิกแล้วเปิดหน้าเอกสารของหัวข้อนั้นหน้าเดียว (ไม่ปนกับหัวข้ออื่น)
- หน้าเอกสารแสดง: breadcrumb, รหัสหัวข้อ, ชื่อ, คำอธิบาย, ชื่อชีต, จำนวนรายการ และตารางแบบ **อ่านอย่างเดียว**
- ปุ่มในหน้าเอกสาร
  - **พิมพ์ / PDF** — ใช้ `window.print()` โดยมี print stylesheet ซ่อน sidebar/topbar ให้อัตโนมัติ
  - **ดาวน์โหลด Excel** — ส่งออกเฉพาะเอกสารนี้
  - **แก้ไขข้อมูล** — พาไปหน้าจัดการฐานข้อมูลพร้อมเลือกชีตของหัวข้อนั้นให้
- ถ้าหัวข้อถูกผูกกับชีตที่ถูกลบ ระบบจะแจ้ง "ไม่พบชีต ..." แทนการแสดงข้อมูลผิด

## 5. ตั้งค่าเมนู / คอลัมน์ (`ตั้งค่า`)

หน้านี้รวมงาน config ทั้งหมดไว้ที่เดียว

### 5.1 สร้าง/แก้ไขโครงสร้างเมนู

ตารางโครงสร้างมีคอลัมน์:

| คอลัมน์ | คำอธิบาย |
|---|---|
| รหัส | รหัสหัวข้อ เป็นลำดับชั้น เช่น `1`, `1.1`, `1.1.1` (ต้องไม่ซ้ำ) |
| อยู่ภายใต้ | เลือกหัวข้อแม่ (เว้นว่าง = หัวข้อหลัก) |
| ชื่อหัวข้อ | ชื่อที่แสดงในเมนูและหัวเอกสาร |
| ชีตข้อมูล | ชื่อชีตที่หัวข้อนี้ใช้เก็บข้อมูล (เว้นว่าง = ไม่ผูก) |
| ไอคอน | ชื่อ Bootstrap Icons เช่น `bi-folder2` (เว้นว่างได้) |
| ลำดับ | ตัวเลขเรียงภายในระดับเดียวกัน |
| คำอธิบาย | ข้อความอธิบายที่จะแสดงใต้ชื่อในหน้าเอกสาร |

ปุ่มที่ใช้:

- **เพิ่มหัวข้อหลัก** — เพิ่มแถวใหม่ระดับบนสุด
- **ไอคอนโหนด (ต่อแถว)** — เพิ่มหัวข้อย่อยภายใต้แถวนั้น รหัสจะถูกสร้างต่อท้ายให้อัตโนมัติ (เช่น `1.1.2`)
- **ถังขยะ** — ลบแถวออกจากตาราง (ยังไม่ถูกบันทึกจนกด "บันทึกโครงสร้าง") ถ้าหัวข้อนั้นมีหัวข้อย่อยจะลบไม่ได้
- **บันทึกโครงสร้าง** — ตรวจสอบและเขียนลงชีต `_MENU` แล้วสร้างชีตข้อมูลให้ถ้ายังไม่มี

ข้อกำหนดตอนบันทึก:

- รหัสและชื่อหัวข้อต้องไม่ว่าง และรหัสต้องไม่ซ้ำ
- หัวข้อแม่ต้องมีอยู่จริง และต้องไม่เกิดวงจร (A เป็นลูก B, B เป็นลูก A)
- **หัวข้อที่มีหัวข้อย่อยห้ามผูกชีตข้อมูล**
- ชื่อชีตในช่อง "ชีตข้อมูล" ถ้ายังไม่มีอยู่จริง ระบบจะสร้างให้อัตโนมัติ

### 5.2 หัวข้อคอลัมน์

1. เลือกชีตจาก dropdown
2. พิมพ์ชื่อคอลัมน์คั่นด้วยเครื่องหมายลูกน้ำ `,`
3. กด **บันทึก**

การเปลี่ยนหัวข้อคอลัมน์จะล้างแถวหัวตารางเดิมและเขียนใหม่ (ข้อมูลแถวยังอยู่ แต่ความหมายของคอลัมน์อาจเลื่อน)

### 5.3 สร้างชีตข้อมูลใหม่

1. พิมพ์ชื่อชีต (เช่น `4.1 ความพึงพอใจ`)
2. กด **สร้าง**
3. กลับไปผูกชีตนี้กับหัวข้อในตารางโครงสร้างเมนู แล้วกด "บันทึกโครงสร้าง"

ชื่อชีตต้องไม่ว่าง ไม่ซ้ำของเดิม และห้ามขึ้นต้นด้วย `_`

## 6. ขั้นตอนทำงานที่แนะนำ (ครั้งแรก)

1. เข้า **ตั้งค่าเมนู / คอลัมน์** → ตรวจ/แก้โครงสร้างเมนูให้ตรงกับแบบรายงาน
2. สร้างชีตข้อมูล (ถ้ายังไม่มี) และผูกให้หัวข้อใบ
3. ตั้งหัวข้อคอลัมน์ของแต่ละชีต
4. เพิ่มข้อมูลผ่านหน้า **เพิ่ม / นำเข้าข้อมูล** หรือ import จาก Excel
5. ตรวจสอบ/แก้ไขในหน้า **จัดการฐานข้อมูล**
6. เปิดดู/พิมพ์รายงานจากเมนู **เอกสารตามหัวข้อ**
